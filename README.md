# 月下文人大挑戰 全班投影版

雙擊同一資料夾的 `index.html`，用 Chrome、Edge 或 Safari 開啟即可遊玩。遊戲不需登入、安裝套件或連線，所有圖像、聲音及題目均內嵌在單一 HTML 中。上傳 GitHub Pages 時，只需上傳 `index.html` 至網站根目錄。

首次使用：請按下「開始溫習」，選擇關卡並按「開始答題」。全班共同討論，由教師操作電腦確認答案，全班共用一個總分。聲音在首次開始後啟動，預設不限時。平板較窄時，「開始答題」按鈕在題目下方。

新版採用明亮的淺藍、淡紫及青綠配色、白色題目卡和深色文字，並放大題目、答案、卡牌及教師按鈕，方便課室投影。

每題的作答畫面僅顯示一個題幹；對話題先呈現情境對話，再顯示一道提問。題庫中的 `title` 僅用作教師選題標籤，不會另作題目標題顯示。

## 四個關卡

| 關卡 | 題數 | 互動玩法 |
| --- | ---: | --- |
| 情境對話理解 | 9 | 逐句顯示書面語情境對話，辨認人物與作品，理解句意、寫作手法及思想感情 |
| 詩文分類、排序與填空 | 12 | 4 項詩文分類、4 項詩文排序、4 項填空 |
| 課文理解與判斷 | 9 | 點選物件選題、判斷正誤、人物背景、事件排序 |
| 三篇作品綜合比較 | 12 | 心境理解、思想感情配對、字詞配對、情感轉變排序、綜合比較 |

共 42 題，每項均有答案及解析。一般題 10 分，部分挑戰題 20 分，全部答對共 510 分。整項分類、排序或配對完全正確才加分。答錯、查看答案、跳過及超時不扣分亦不加分。每題只結算一次，防止重複加分。教師可直接修改總分，以配合口頭補答或額外獎勵。

排序：可將卡牌拖曳至排列區，亦可依次點選卡牌。使用「前移／後移」調整次序；點選已排列的卡牌可將其移回。拖到已排的卡牌上可插入該位置。

分類及配對：可將卡牌拖曳至目標區域，或先點選卡牌，再點選目標區域。點選已放置的卡牌後，可將其移至其他區域。適合觸控及鍵盤操作。

## 教師控制

- 全班共同作答，無須選組。教師可在控制台直接修改全班總分。
- 四關可自由選擇；題目可用右方題號或控制台選取，不必依次完成。
- 倒數可關閉或設為 10–600 秒；每題手動開始，可暫停、繼續或重設。
- 打開控制台、「課文原文」視窗及說明視窗，或切換到其他分頁時，未完成題目會暫停。
- 重新開始本關會移除本關作答及自動所得分，保留其他關得分和手動調整。重設整個遊戲會清除全部作答及分數，保留聲音／計時設定。
- 可隨時進入「查看全班成績」查看本次總結；完成全部題目後也會提供總結入口。
- 完成全部關卡後，可查看本次溫習總結。結算畫面顯示全班總分、完成題數及答對題數。
- 背景音樂已更換為 Kevin MacLeod 的〈Life of Riley〉錄製配樂，以結他、烏克麗麗、鐘琴及敲擊樂伴奏。音檔內嵌於單一 HTML 中，可離線播放；預設播放音量較低。音樂及音效可分別開關，也有總音量控制及全螢幕按鈕。

## 保存進度

遊戲使用 localStorage 自動保存這個瀏覽器、這個網址下的全班分數、作答、卡牌位置及剩餘時間。重新整理後，未完成題目會保持暫停。不同瀏覽器、檔案位置或網址的紀錄可能不共用；清除瀏覽資料亦會移除進度。

轉移裝置或上課前備份：教師控制台 →「匯出進度」。在另一部裝置開啟遊戲後，選「匯入進度」載入備份。備份包含當時題庫、全班分數及設定。匯入前會顯示取代現有資料的確認。

舊版紀錄會自動轉換：各組已得分及手動調整會合併為全班總分，作答及卡牌進度繼續保留。舊版進度備份亦可匯入。

## 修改題庫

教師控制台 →「編輯／匯入題庫」。可直接修改 JSON，或匯出後用文字編輯器編輯，再匯入。程式會檢查 ID、題型、答案索引、必需欄位及四關是否都有題目。套用題庫會移除全部作答及自動所得分，保留手動調整及設定。頁內修改保存在該瀏覽器中。

如要把改好的題庫永久放進 HTML，將匯出的 JSON 內容替換 `index.html` 中 `<script id="question-bank" type="application/json">` 與緊接的 `</script>` 之間的資料。不要刪除兩個 script 標籤；題目內容不要包含字面 `</script>`。

每題共用欄位：`id`（不可重複）、`stage`（1–4）、`type`、`title`（教師選題標籤）、`prompt`（唯一題幹）、`answer`、`explanation`、`difficulty`（簡單／中等／挑戰）、`work`、`points`（1–100 整數）。可另加 `mode` 作畫面題型標籤。

| type | 額外欄位 | answer 的格式 |
| --- | --- | --- |
| choice | options：選項文字陣列 | 正確選項的索引，由 0 開始 |
| chat | options、messages：對話訊息陣列、reveal：揭曉人物名 | 正確選項索引 |
| sort | items：卡牌文字陣列 | items 索引的正確順序，例如 `[2,0,1]` |
| classify / match | items：卡牌、targets：目標區文字陣列 | 依 items 次序列出各卡所屬 targets 索引，例如 `[0,2,1]` |

偵探題可加 `object`，內建名稱：卷軸、足跡、畫像、書信、玉印、明月、古書、燈籠、摺扇。其他名稱會用通用線索圖示。

## 教材與核對

主要依據教師提供的三份 HFCC 教師版筆記；以原文為基礎，並核對教育局篇章配套：

- [教育局：《水調歌頭‧明月幾時有》（並序）](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS3_17.pdf)
- [教育局：《記承天寺夜遊》](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/resources/primary/lang/jileiwen/jilei_wen_040.pdf)
- [教育局：《虞美人‧春花秋月何時了》](https://www.edb.gov.hk/attachment/tc/curriculum-development/kla/chi-edu/recommended-passages/KS3_13.pdf)

對話內容以書面語根據課文改寫，並非真實歷史對話。「閒人」保留閒適、失意、自嘲，以及對世人缺少賞景閒情的感慨；《水調歌頭‧明月幾時有》保留仕途失意、矛盾、思念弟弟、自我開解及祝願的層次；《虞美人‧春花秋月何時了》保留故國之思、物是人非及亡國之痛。原文未交代張懷民未睡的確切原因；以東風推測春天屬文本推論，不作確切創作日期的史實。筆記的明顯誤植沒有沿用。
